# Criteria

## Overview

This policy detects ad-hoc, instance-specific fixes, single-case carve-outs, or localized exceptions that fail to apply to the broader class of similar problems. When an agent proposes a solution, rule, or fix, it must target the general class rather than special-casing a single instance. When this policy fires, the action or proposal must be revised to state a general rule or escalated for proper framework-level rulemaking.

## Definition of Terms

- **Agent response**: The draft text, code, or proposal generated by the AI agent.
- **Instance-Specific Carve-Out**: A modification, rule, or workaround engineered to apply exclusively to a single file, user, task ID, or ad-hoc instance while ignoring identical cases in the same class.
- **Class-Targeted Rule**: A design, policy, or implementation change formulated as a universal rule applying to all members of a defined category or domain.
- **Task context**: The reference material provided alongside the **Agent response**, containing the user's **Current request** and **Standing instructions**.

## Interpretation of Language

- Evaluate whether a proposed fix, rule edit, or refactoring in the **Agent response** addresses a general class or creates a one-off exception.
- Single-instance hardcoded conditionals, special-cased path checks for specific temporary IDs, and ad-hoc exceptions that cannot be justified as general principles match this policy.
- Systemic refactorings, parameterizations, and general rule abstractions that cover all instances of a category do not match.

## Definition of Labels

### (CI): Instance-Specific Carve-Out

#### Includes

- **Single-Instance Hardcoding Class**: An **Agent response** adding a conditional branch or exception targeted at a single specific identifier, file path, or task instance rather than handling the underlying category structurally.
- **Ad-Hoc Exception Grant Class**: An **Agent response** inventing a local exception to a general framework rule or constraint without stating a universal, class-wide principle.
- **Narrow Local Fix Class**: An **Agent response** patching a symptom in a single location while leaving identical patterns unaddressed across the parent class.

#### Excludes

- **Class-Wide Abstraction Class**: An **Agent response** introducing a general rule, utility function, or schema modification that applies uniformly across all instances of a class.
- **Targeted Domain Fix Class**: An **Agent response** fixing a specific bug by correctly implementing a general class-level protocol or contract.
- **Escalation for Rulemaking Class**: An **Agent response** identifying an unforeseen edge case and escalating to the user or framework authority for a general rule instead of applying a local hack.
