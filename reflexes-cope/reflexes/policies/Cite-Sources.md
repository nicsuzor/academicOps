# Criteria

## Overview

This policy inspects an agent's proposed response and fires when non-trivial factual, analytical, or attributive claims are asserted without citing a verifiable source. Every material claim must be attributed to an explicit file path, line range, user directive, framework axiom, external URL, or subagent finding. When this policy fires, the agent must attach explicit source attributions to its claims.

## Definition of Terms

- **Agent response**: The draft text, report, or summary generated by the AI agent.
- **Unattributed Claim**: A non-trivial factual, technical, or analytical assertion presented in the **Agent response** without referencing the underlying source (e.g. file:line, user quote, doc link, subagent trace).
- **Valid Source Citation**: An explicit reference within the **Agent response** pointing to a specific file path and line number, a direct quote from the user request, an axiom slug, a URL, or a subagent audit trace.
- **Task context**: The reference material provided alongside the **Agent response**, including **Actions this turn** and **Current request**.

## Interpretation of Language

- Inspect the **Agent response** for statements presented as facts or findings.
- Check whether non-trivial statements link back to observable evidence, inspected files, user directives, or external documentation.
- General conversational prose, greeting text, or direct restatements of user inputs do not require citations.

## Definition of Labels

### (CS): Unattributed Factual Claim

#### Includes

- **Uncited Technical Assertion Class**: An **Agent response** making specific claims about system architecture, code behavior, or performance metrics without citing file paths, line numbers, or test logs.
- **Laundered Subagent Claim Class**: An **Agent response** repeating a subagent's conclusion or finding without propagating the underlying source file or empirical evidence.
- **Unattributed Historical or Domain Fact Class**: An **Agent response** asserting external domain facts or historical data without providing source documentation or web citations.

#### Excludes

- **Attributed Code Citation Class**: An **Agent response** citing precise file locations (e.g. `file:///path/to/file#L10-L20`) or commit hashes for every technical claim.
- **User Directive Quoting Class**: An **Agent response** referencing or quoting explicit instructions provided directly in the **Current request**.
- **Axiom and Spec Reference Class**: An **Agent response** citing specific framework axioms or specification documents by slug or path.
