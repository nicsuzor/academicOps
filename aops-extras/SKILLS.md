# aops-extras Skills Index

Replaceable **technology-specific** academic skills. Where the `aops-tools` `analyst`
skill holds the tech-agnostic principles (data immutability, transformation layer vs
presentation layer, statistical methodology), these skills hold the concrete _how-to_ for
particular tools. They are deliberately **swappable** — drop one for an official or
community-consensus skill whenever a better one exists.

## Skills

| Skill        | Triggers                                              | Description                                                                       |
| ------------ | ----------------------------------------------------- | --------------------------------------------------------------------------------- |
| `dbt`        | `dbt`, `dbt model`, `dbt project`, "staging model"    | dbt implementation of the analyst **transformation layer** (models, tests, marts) |
| `streamlit`  | `streamlit`, `streamlit app`, `dashboard`             | Streamlit implementation of the analyst **presentation layer** (display only)     |
| `python-viz` | `matplotlib`, `seaborn`, `statsmodels`, "python plot" | Python plotting & statistical-modelling libraries for figures and model fitting   |

See the `analyst` skill in **aops-tools** for the tech-agnostic principles these skills implement.
