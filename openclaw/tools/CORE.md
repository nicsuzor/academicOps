# tools Plugin Core

- **Research Analysis**: Use `tools:analyst` for reproducible data pipelines; keep raw research data immutable and separate transformation from presentation.
- **Transformations & Viz**: Use `tools:dbt` for SQL models, `tools:python-viz` for statistical plots, and `tools:streamlit` strictly for read-only metric displays.
- **Publishing & Documents**: Use `tools:pdf` for Pandoc/Weasyprint typesetting, `tools:diagram` for Mermaid and Excalidraw diagrams, and `tools:madr` for Architectural Decision Records.
- **Academic Review**: Use `tools:peer-review` for scheme-agnostic grant and academic peer review.
- **Project Scaffolding**: Use `tools:new-project` to scaffold new research repositories with canonical layout and CI/CD.
