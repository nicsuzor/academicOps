# Enforcement map

The enforcement map is a concise cross-reference table showing what kind of enforcement is applied to each rule. When editing the enforcement map, every row must **only** reference a specific rule derived from our axioms ([`plugins/rbg/skills/axioms/`](../plugins/rbg/skills/axioms/)) and applicable to agents working in any third-party project -- never repository-local project rules, subsystem feature specifications, or workflows. Workflows are not rules and do not enforce rules; creating or modifying workflows must not produce token enforcement map rows, as the only applicable rule is "agents must follow workflows given to them" and nothing more than that. See [`enforcement/enforcement.md`](enforcement/enforcement.md) for governing principles and [`enforcement/enforcement-map.md`](enforcement/enforcement-map.md) for schema and inclusion rules.

**Universal axiom baseline (applies to every `trigger: always_on` axiom below):**

- **Client rule injection (`structural`, `protection` / `friction`):** [`build/axioms.py:19-52`](../build/axioms.py#L19-L52) extracts every `trigger: always_on` axiom from [`plugins/rbg/skills/axioms/`](../plugins/rbg/skills/axioms/). [`build/clients/claude.py:50-61`](../build/clients/claude.py#L50-L61) mirrors `*.md` into `.claude/rules/` and merges `axioms.jsonl` into `~/.claude/settings.json` `autoMode.soft_deny` ([`auto-mode-classifier.md`](enforcement/auto-mode-classifier.md)); [`build/clients/agy.py:49-80`](../build/clients/agy.py#L49-L80) copies `*.md` into Antigravity `rules/`; [`build/clients/openclaw.py:46-51`](../build/clients/openclaw.py#L46-L51) writes `axioms.jsonl`.
- **In-session evaluator & stop gate (`JIT injection` / `structural`):** [`plugins/rbg/hooks/rules.py:140-190`](../plugins/rbg/hooks/rules.py#L140-L190) loads rules across scopes (`skills/axioms/`, project `.agents/rules/`, user `$COPE_USER_RULES_DIR/*.md`); [`plugins/rbg/hooks/handlers.py:305-311`](../plugins/rbg/hooks/handlers.py#L305-L311) evaluation/stop handlers `[DISABLED]` while ambient axiom injection remains active across harnesses.
- **Rule-compliance review lens (`process`, `required gate`):** [`plugins/rbg/agents/rbg.md`](../plugins/rbg/agents/rbg.md) evaluates target artifacts against axioms, project rules, and PKB user rules (`type: rule`) via [`wf-rbg.md`](../plugins/ida/skills/workflow-library/workflows/wf-rbg.md), [`wf-dialectical-review.md`](../plugins/ida/skills/workflow-library/workflows/wf-dialectical-review.md), and [`/strategic-review`](../plugins/ida/skills/strategic-review/SKILL.md).
