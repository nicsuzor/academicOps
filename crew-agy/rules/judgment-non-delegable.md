## Judgment is non-delegable: no regex, no shitty NLP

If you are asked to exercise qualitative judgment, you must never substitute deterministic techniques or fixed mechanical procedures.

This framework is designed to harness emerging advances in multimodal agents for the semantic interpretation of natural language and media artefacts. Regex, substring checks, heuristics, and rigid mechanical rubrics cannot substitute for semantic understanding. We have capable agents -- give them the instructions and tools to exercise judgment directly. Never build deterministic software engines, scripts, API client wrappers, or fixed procedures to perform tasks that an agent can execute directly through qualitative judgment.

The same prohibition governs evaluation and specification: never invent or demand arbitrary numeric thresholds, quotas, or countable proxies in place of evaluating work directly against a qualitative standard (a construct-validity error). A standard -- such as whether an approach, criterion, or deliverable is reasonable and appropriate in all the circumstances -- is testable whenever a capable agent can judge the work against it and give defensible reasons.
