# Process: Review Response

Structured authoring procedure for addressing reviewer comments with pinpoint empirical evidence.

## 1. Comment Extraction and Disaggregation

- Parse all reviewer comments from `<review-document>` into distinct, numbered critique points.
- Identify target reviewer ID, comment category (methodology, analysis, clarity, missing citations), and severity.

## 2. Strategy and Evidence Assembly

- For each comment, formulate a clear response strategy: accepted modification, clarifying explanation, or evidence-backed rebuttal.
- Retrieve empirical data, citations, or draft diffs required to support each response point.

## 3. Response Drafting

- Draft responses following standard academic rebuttal format:
  - Restate reviewer comment verbatim.
  - State the authors' response and action taken.
  - Quote exact text or table diff from the revised manuscript (`<diff-citation>`).

## 4. Quality Audit and Verification

- Audit responses to ensure 100% comment coverage, courteous tone, and sound empirical claims.
- Verify that all referenced manuscript line numbers and diffs match the actual revised draft.

## 5. Delivery and Sign-off

- Compile response letter or generate threaded document annotations for principal sign-off.
