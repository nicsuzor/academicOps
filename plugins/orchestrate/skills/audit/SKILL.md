This skill is for post-hoc forensics and hierarchical subagent dispatch tracing across transcript files generated by aops. These files are stored in $AOPS_SESSIONS (the 'sessions' repo). Don't go back to the original agent harnesses, use our records always.

# Audit: Session Transcript & Subagent Trace

Use this skill to investigate session logs, audit multi-agent coordination, and reconstruct hierarchical execution trees across transcript files generated
by `aops transcript.py` in `$AOPS_SESSIONS` (defaults to `~/src/sessions`).

---

## 1. Fast Session Discovery

Search `$AOPS_SESSIONS` rapidly using `fd` and `rg`:

```bash
# Set session root fallback if unset                                                                                                                       
AOPS_SESSIONS="${AOPS_SESSIONS:-$HOME/src/sessions}"                                                                                                       
                                                                                                                                                            
# 1. Locate recent sessions dispatching subagents or polecats (last 24 hours)                                                                              
fd --changed-within 1d -tf --exec-batch rg "for dispatching agy" "$AOPS_SESSIONS"                                                                          
                                                                                                                                                            
# 2. Find sessions matching a specific task or dispatch command                                                                                            
fd --changed-within 7d -tf --exec-batch rg "dispatch-<task-id>|run agy" "$AOPS_SESSIONS"                                                                   
                                                                                                                                                            
# 3. Locate timeouts, permission halts, or unhandled errors                                                                                                
fd --changed-within 1d -tf --exec-batch rg -i "permission prompt|timed out|ToolException|Encountered error" "$AOPS_SESSIONS"                               
                                                                                                                                                            
# 4. Search transcripts by user intent or keyword                                                                                                          
fd --changed-within 3d -tf --exec-batch rg -i "<query-or-phrase>" "$AOPS_SESSIONS"                                                                         
──────                                                                                                                                                       
## 2. Hierarchical Subagent Tracing

Reconstruct parent-to-child dispatch sequences across session transcripts:

### Step 1: Identify the Root Session

Find the initiating session where the request was received:

fd --changed-within 1d -tf --exec-batch rg -l "<search-query>" "$AOPS_SESSIONS"

### Step 2: Extract Dispatch Signatures

Inspect the parent log for child dispatch metadata:

• Polecat dispatches: NAME="dispatch-<task-id>", CMD="uv run python3 ... polecat/cli.py run agy ..."
• Subagent dispatches: invoke_subagent, sender=<conv-id>, Recipient=<conv-id>
• Tool calls: for dispatching agy, background task identifiers

### Step 3: Map Child Transcripts

Locate the corresponding child transcript in $AOPS_SESSIONS:

fd -tf --exec-batch rg -l "<child-session-or-task-id>" "$AOPS_SESSIONS"

### Step 4: Reconstruct Execution Tree

Trace the timeline and identify bottlenecks or failure points:

Root Session: 2026-08-14-session-root.md
├── [15:15:00] User Request: "<request>"
├── [15:15:53] Subagent Dispatch (task-481 / conv-child-1)
│   └── Child Session: 2026-08-14-dispatch-task-481.md
│       ├── [15:15:58] Subagent Start
│       ├── [15:16:56] Tool Execution / Timeout / Error
│       └── [15:17:10] Result Report -> send_message
└── [15:17:24] Coordinator synthesizes result and completes task
──────
## 3. Auditing Checkpoints

When evaluating transcripts:

• Dispatch Integrity: Verify base commits (--base $(git rev-parse HEAD)) and matching session names (-s $NAME).
• Friction Points: Identify blocking permission prompts, unhandled tool exceptions, or connection timeouts.
• Loop Detection: Flag redundant tool calls, missing reactive wakeups, or stuck sleep cycles.
• Handoff Quality: Verify subagents reported structured findings back via send_message and persisted outputs to durable storage.
```
