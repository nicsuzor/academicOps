# Daily

Update today's daily note and reply with a scannable run-down on Telegram.

The canonical daily note procedure is defined in universal workflow template `wf-daily`.

1. Run `wf-daily` to read, enrich, and reconcile today's daily note in the PKB.
2. Reply on Telegram with a scannable run-down of today's priorities, completed work, and open decisions in `## With you`.
