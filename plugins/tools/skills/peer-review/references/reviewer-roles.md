# Reviewer Roles

Determine the evaluation role at intake to align drafting scope and format.

## Roles

- **Detailed Assessor** (ARC detailed, ERC remote referee, SNSF external referee):
  - In-depth evaluation of single applications; no cross-application comparisons.
  - Produce full evidence-cited comments per criterion (meeting scheme character minimums).
  - Text directly informs applicant rejoinders; comments must justify final scoring.
- **General Assessor / College of Experts** (ARC SAC, ERC panel, SNSF panel):
  - Moderation and ranking across a broad pool under finite time.
  - Triangulate Detailed Assessor scores/comments against proposal text and disciplinary judgment.
  - Generate concise panel-facing notes defending ranking decisions rather than lengthy criterion comments.
- **Collegial Draft Reviewer**:
  - Review pre-submission papers or grant drafts for colleagues using Scribe Mode in SKILL.md.
  - Focus feedback on core structural priorities budgeted to the author's timeline.
- **Journal Peer Reviewer**:
  - Focus on empirical validity, methodological rigor, and claims-to-data fit.
  - Separate publishability recommendation from technical critique.

## Cross-Role Standards

- **One-time CoI scan**: Record conflicts at intake as a header flag; require human reviewer confirmation against private collaboration records before submission.
- **Tone and integrity**: Focus on proposal mechanics, never personal attributes; route integrity concerns out-of-band.
- **Independent formulation**: Draft assessments prior to reading other assessors' evaluations to prevent consensus capture.
