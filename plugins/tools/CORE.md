# tools Plugin Core

- **Research Analysis**: Use `tools:analyst` for reproducible data pipelines; maintain raw research data immutability and separate transformation from presentation.
- **Transformations & Viz**: Use `tools:dbt` for SQL models; use `tools:python-viz` for statistical plots; use `tools:streamlit` strictly for read-only metric displays.
- **Publishing & Documents**: Use `tools:pdf` to typeset markdown documents via Pandoc/Weasyprint; use `tools:diagram` for Mermaid and Excalidraw diagrams.
- **Academic Review**: Use `tools:peer-review` for scheme-agnostic grant and academic submission evaluations.
- **Project Scaffolding**: Use `tools:new-project` to initialize new research repositories with canonical directory structures and CI/CD.
