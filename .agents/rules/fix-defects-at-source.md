## Fix defects where they live

A defect or limitation in a tool, MCP server, library, or configuration file must be fixed in that component or filed as an issue against it.

- Do not add skill steps, extra refresh calls, retries, or procedural workarounds to compensate for broken upstream tools.
- If a configuration or file is in the wrong location, move it to the correct path rather than adding path workarounds in code or instructions.
