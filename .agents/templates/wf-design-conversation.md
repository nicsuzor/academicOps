# Process: Interactive Design Conversation

Collaborative design process to refine ambiguous requirements into validated specifications.

## 1. Context and Problem Framing

- Explore the core user intent, constraints, and problem background for `<topic>`.
- Identify key unknowns and open architectural questions.

## 2. Option Exploration and Dialogue

- Present alternative approaches with clear trade-offs (simplicity vs flexibility, performance vs complexity).
- Solicit user feedback on specific design choices using targeted questions.

## 3. Iterative Artifact Drafting

- Draft preliminary design artifact (spec, schema, or workflow outline) in scratchpad.
- Incorporate user feedback across conversational turns, refining structure and boundaries.

## 4. Specification Formalization

- Formalize converged design into a complete specification (`develop-specification`).
- Verify alignment with codebase axioms and existing conventions.

## 5. Review and Sign-off

- Present final specification summary to user for sign-off.
- Route approved specification to implementation planning (`/decompose`).
